# 映画GIFT｜Web操作デモ

[公開モック](https://ayaka1933-glitch.github.io/eiga-gift-web/)

Going Soon・ねぎらい予約GIFT・落ち着いたら行こう・布教券・ごめんねGIFTの5つの操作フローです。

布教券は、作品・おすすめ文・色・名前を選び、作成した券面をPNG（1,200×900px）で保存・SNS共有できる試作です。LINEで受け取る画面のデモもあります。

各フローに画面切り替えと完了時のモーションを付けています。端末の「視差効果を減らす」などの設定ではモーションを無効にします。

企画の説明資料、サンプリング写真、広告・SNS投稿イメージは公開内容に含みません。実際の決済・予約・映画GIFT発行・送信は行いません。券面はデザイン見本で利用できません。入力は端末のlocalStorageだけに保存し、サーバーには送信しません。

## 公開と保管

このサイトはGitHub Pagesで配信し、ChatGPTの認証・API・ホスティングには依存しません。GitHubアカウント・リポジトリ・Pagesの設定が維持されている間、ChatGPTアカウントの削除によってこのデプロイが削除される構成ではありません。GitHubアカウントやリポジトリを削除すると、サイトも失われます。

## ローカルで表示

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。ビルド・追加ライブラリは不要です。

## 固定QRと更新

QRは `?case=going` などの固定URLを使用します。公開更新ごとにQRやURLを変更する必要はありません。

`index.html` はキャッシュを使わず `release.json` の公開版番号を確認し、その版のCSS・JavaScriptを読み込みます。タブへ戻ったときも版を確認します。今後の更新では `release.json` の `version` を必ず更新してください。接続失敗時の予備版番号と最初のCSS版番号も `index.html` で合わせて更新します。

以前のHTMLが端末に残っている初回は、ページを再読み込みすると新しい読み込み方式に切り替わります。開いているページに新しいコードを直接配信する仕組みではありません。
